# CodeAlpha_Calculator
A responsive web-based calculator built with HTML, CSS, and JavaScript. Supports basic arithmetic operations (+, -, ×, ÷, %), real-time result display and keyboard input. Designed for usability, accessibility, and smooth interaction across devices.

## ✨ Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Percentage calculation (`%`)
- Clear (`C`) and Delete (`⌫`) functions
- Real-time result display
- Keyboard support:
  - Numbers and operators (`+ - * / % .`)
  - `Enter` → equals
  - `Backspace` → delete
  - `Escape` → clear
- Responsive design with modern styling
